# Data Analysis & QA Validation

This project uses the **AdventureWorks2022** sample database to demonstrate practical SQL-based data analysis and QA validation.

## Objectives

* Analyze sales and product data
* Identify patterns and useful information in the database
* Validate relationships between related tables
* Identify missing, inconsistent, or potentially invalid data
* Document findings and observations from a QA perspective

## Project Structure

* `analysis_queries.sql` – SQL queries used for data analysis
* `qa_validation_queries.sql` – SQL queries used for data-quality and validation checks
* `findings.md` – Results, observations, and QA conclusions

## Database

**AdventureWorks2022**

## Tools

* **SQL Server Management Studio (SSMS) 22**
* **Microsoft SQL Server**

## Focus Areas

* Data analysis
* Data validation
* Data quality checks
* NULL value checks
* Referential integrity
* Duplicate detection
* Business-rule validation
* SQL JOINs and aggregations

## Purpose

The goal of this project is to demonstrate practical SQL skills relevant to **QA and software testing**, including data investigation, validation, and analysis.
