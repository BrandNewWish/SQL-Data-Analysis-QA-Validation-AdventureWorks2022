# SQL Data Analysis & QA Validation – AdventureWorks2022

This repository contains my SQL practice exercises and a data analysis / QA validation project using the **AdventureWorks2022** sample database.

## 📁 Repository Structure

### 01_SQL_Queries

A collection of SQL exercises covering fundamental and intermediate SQL concepts.

Topics include:

* SELECT statements
* WHERE filtering
* DISTINCT
* ORDER BY
* NULL and NOT NULL
* LIKE and pattern matching
* GROUP BY
* HAVING
* Aggregate functions
* COUNT
* INNER JOIN
* Combining data from multiple tables
* Working with primary key / foreign key relationships

### 02_Data_Analysis_QA_Validation

Data analysis and QA validation project using the AdventureWorks2022 database.

This section will include:

* Data analysis queries
* Data quality checks
* Validation of relationships between tables
* Identification of missing or inconsistent data
* Findings and observations

## 🗄️ Database

**AdventureWorks2022**

The exercises and validation queries are written for Microsoft SQL Server.

## 🎯 Purpose

The goal of this repository is to demonstrate practical SQL skills relevant to **QA and software testing**, including data investigation, validation, and analysis.
